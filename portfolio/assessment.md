# Assessment

Assessment models, assessment mechanisms, measurement and evidence assets.

Assessment capability currently lives inside the semantic foundation rather than in standalone repositories: the metamodel carries a dedicated assessment layer (frameworks own maturity; results carry evidence, confidence and provenance; gaps connect to change), evolved through the CR-005 and CR-AM change-request series in [`dea-metamodel`](https://github.com/technehub-labs/dea-metamodel/tree/main/change-requests). The [`dea-catalog-metrics`](https://github.com/technehub-labs/dea-catalog-metrics) repository provides the Performance Metric catalog adjacent to this family.

This family activates as standalone assessment repositories are established through the change-request process.
